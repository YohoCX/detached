| Diff notes to a chat | Notes on diff lines collect into one review; Send composes them, line-anchored, into one prompt for a chosen chat or a new one. Unresolved notes go into the next send. |
| Continue a chat in the terminal | Copies a chat into a terminal tab (`claude --resume`, `codex resume`) and a CLI conversation back into a chat. |
| Hibernate idle chats | A finished chat that is not on screen and untouched for N minutes (30 by default) stops its process and resumes when opened again; off while it waits for an answer or has a running subagent. |
| Files and images in the prompt | Drop files from Finder or the project tree onto the composer, paste an image from the clipboard; a file goes in as a path mention, an image as the agent's image content. Dropping a file on a terminal pastes its path. |
| Several agent accounts | Add Claude Code and Codex accounts in Settings › Agents, each in its own config home (`CLAUDE_CONFIG_DIR`, `CODEX_HOME`) and logged in by its CLI there, so adding one never signs another out; the system login stays as the default. Pick the account per chat or as the default, switch from the limits chip in the status bar. A limits popover lists every account's windows, the tightest first, with a warning at 80%. On remote dev, accounts belong to the host. |
| Bots on the home host (idea, not planned) | A bot takes a task from an issue, a schedule or a webhook, runs a chat in its own worktree and opens an MR for review in the client. Runs on the always-on host of remote dev, not a VPS. |
| Council calibration | Replaces the corpus pass removed in 0.6.1 ([decision](decisions/2026-11-19-council-calibration.md)). Passive: precision, noise and verifier agreement per role, lens, model and mode from the owner's Fix, Dismiss and Defer, with a suggestion once 5 decisions stand behind it. Opt-in benchmark: pick the subjects, 3 by default; the estimate is diff size × participants × the user's measured tokens per KB, shown in tokens and as a share of the weekly plan limit; a confirm, a budget of the estimate × 1.5, Cancel; then a per-bug caught/missed table and a comparison with the last pass. |
| Plugins from a folder | Each plugin is global (all workspaces) or a workspace's own, installed and turned on per scope. A manifest with themes and TUI tabs through the terminal; a manifest over a JSON CLI whose `source` fills a table and whose `actions` run commands, with a confirm before destructive ones. One consent, "this plugin runs code as you", shown again when its files change; no per-permission screen, since without a sandbox it would imply a limit that is not there. A per-tab opt-in to the terminal env, never for a plugin's TUI tab. `ACTIONS` stays for built-ins and a runtime table takes namespaced ids from manifests, unknown ids refused softly, with one rebind path; CLAUDE.md's key rule and docs/KEYMAP.md change with it. Done when a `local-postgres` manifest lists databases from `pg-dev` and drops one after a confirm, in a test on a fake CLI. |

Done when the owner starts a session in a new worktree with its own DB from the app and removes it again. Needs plugins from a folder. |
| A free, committing agent on untrusted code | A sandboxed full clone per agent, its result taken back as a bundle made inside the sandbox; today an untrusted subject gets a read-only review and no Fix ([decision](decisions/2026-11-12-untrusted-read-only.md)).
