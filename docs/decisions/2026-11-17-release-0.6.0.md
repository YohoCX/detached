# 0.6.0 ships as a regular release, with Codex

**Decided by the owner on 2026-11-17.**

## What was decided

- **0.6.0 is a regular release**, not a prerelease, published without waiting for Anthropic's
  answer to the owner's letter of 2026-11-16
  ([decision](2026-11-16-claude-direct-connection.md), choice 5).
- **Codex is in it**, through `codex-acp` 2.6.0 from the signed adapter catalog
  ([decision](2026-11-17-catalog-signed-in-ci.md)), off until the user turns it on.
- **If Anthropic objects**, a 0.6.1 follows with what the answer asks.

## Why

- Claude Code's terms explicitly allow an end user to sign in to the unmodified binary with their
  own subscription, even where a platform runs it. Detached runs the user's own unmodified
  `claude` on the user's own login; the letter only asks for confirmation.
- 0.5.x users get a release only through the auto-update, which reads `releases/latest`.

## Codex's live check

`make codex-live` could not run before the release: the owner's Codex usage limit resets on
2026-11-19. Codex is covered by the `fake_acp` tests and by H13a's live runs on macOS, made before
the limit.

## Rejected

- **A prerelease:** `releases/latest` skips it, so 0.5.x users would not get it.
- **Waiting for the reply.**
