# The foundation before the features, and the plan in two documents

Decided by the owner on 2026-11-10: "No hurry; we do everything right, on the right
architecture."

- The foundation (kernel, registries, settings, updates, resources, the watcher) comes first, as
  [PLAN-FOUNDATION.md](../../PLAN-FOUNDATION.md). The agent host is a second document written
  against the code the foundation left.
- Why: shipping a feature early is not a goal; each piece of state gets one owner first.
- Rejected: one plan with the host and the foundation interleaved, which put kernel content before
  the kernel decision and shipped nothing for five steps.
