# The ACP agent host ships before the next release

Decided by the owner on 2026-11-12.

- No release of the foundation alone: the next release carries the agent host and the panels,
  built in gated steps and released once at the end.
- Why: the owner wants the complete product, not an interim one.
- Rejected: 0.6.0 now with the foundation and the bun sidecar, which would have put the new kernel
  and watcher in users' hands sooner and tested the new updater one release earlier.
- Meanwhile the owner works on local builds made after each step.
