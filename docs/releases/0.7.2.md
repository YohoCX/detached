# Detached 0.7.2

## Chats

- **Images and files go into a message.**
  - Paste an image or drop it on the composer.
  - Drop files from Finder, Explorer or the project tree. A text file up to 100 KB goes in with its contents. A
    bigger file or a binary goes as a link to its path, and its chip says so.
  - Attachments show as chips you can remove. They stay with the message in history and in Archive.
- **A long paste becomes a chip:** "Pasted text · N lines", with a preview on hover and a click to expand it. It is
  sent whole.
- **Send while the agent works, and the message waits in a queue.** Queued messages show above the composer and go
  one turn each when the turn ends well. Stop, or a failed turn, puts them back in the composer.
- **An agent can start a Council.** Settings › Agents › "Agents start a Council" sets it:
  - **Ask** (the default): a card in the chat with Start, Always and Decline;
  - **Without asking**;
  - **Never**.

  Trust rules do not change, and a Council's own agents cannot start one.
- **Antigravity** joins Claude Code and Codex. Turn it on in Settings › Agents; it runs on your `agy` CLI.
  Permission modes are named the same for every agent.
- A chat with background tasks running shows as working, not done.
- A long chat no longer slows typing: only the messages on screen are laid out.

## Files

- **Detached opens code and Markdown files from Finder, Explorer and the file manager**, and from `detached <file>`.
  - A file in a workspace repository opens in the session that holds it.
  - Any other file opens as a plain tab, which offers to add its git repository to the workspace.
- **Files are edited and saved in their tab** with Cmd+S.
  - The tab marks unsaved changes.
  - Closing a changed tab or the window asks first.
  - A change on disk reloads the tab, or asks when you have edits.
  - Files from Archive open read-only.

## Council

- **The start form is four steps on one page:** what to review, how, who, and access. The estimate and Start stay at
  the bottom, and the preview updates as you change the form.

## Sessions

- **The Sessions list leaves ready repositories to Explorer.**
  - A session shows only the repositories that need a look.
  - Its row counts changed files.
  - Remove from session moved to the repository rows in Overview.
