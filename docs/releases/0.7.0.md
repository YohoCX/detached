# Detached 0.7.0

## Sessions and worktrees

- **Main checkouts** shows each repository on its current branch. For work that spans several repositories, create a named session, pick the repositories, and enter the branch name once. You can also bring existing worktrees into a session.
- **Find your place again.** Files, Go to File and Find in Files follow the selected session. Split a pane to keep a diff, a chat and a terminal side by side. Switching sessions restores the layout and keeps running chats and shells alive. Open the session switcher with Cmd+K on macOS or Ctrl+Shift+K on Windows and Linux.
- **Archive** an idle session to keep its worktrees and tabs for later. You can resume it from the switcher. Chats and tabs from the previous layout are available for reading in Archive.

## Overview

- In **Main checkouts**, see which repositories have changes or are behind their upstream. Open a changed file or pick a branch from its repository row.
- In a **named session**, inspect working changes across its repositories and open the diff for a file. **Needs you** brings pending decisions and worktree problems into view. **Running** shows active work in the session.

## Chats and appearance

- Save your usual chat settings as a default preset. A turn shows the model and effort it used. Settings also shows whether each agent CLI is signed in.
- **Delete** is available for chats Detached identifies as its own. You can still read earlier conversations from Claude Code and Codex in Archive.
- **Slate** is the default theme in light and dark mode. Selected tabs, sidebar rows and menu items have clearer contrast.
- When a terminal tab or pane closes, its surviving shell immediately receives keyboard input. A diff that finishes loading also leaves the keyboard in the checkout picker while you are typing there.
