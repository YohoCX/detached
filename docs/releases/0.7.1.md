# Detached 0.7.1

## Chats

- **A chat starts its agent when you send the first message.** Opening a chat, picking a model or changing the preset starts nothing. If the agent fails to start, your prompt comes back to the composer, and Stop works while it is still starting.
- Models, efforts and your account plan show before the first message, from the last time the agent ran.
- A past conversation opens as history without starting an agent, and resumes when you send a message. Past Codex conversations are listed even before its adapter is installed.
- Text, tables, your messages and the composer share one centered column. A tool call with a multi-line command shows its first line, and a Codex log line no longer becomes a chat's title.
- A link to a local file in an agent's reply opens. A file in a workspace repository opens in the viewer at its line; any other file opens in its system app.

## Sessions and Overview

- A session's chats are where you look for them: in the Sessions list with their state, in Explorer's new Chats mode, and in a Chats block in Overview with "All chats…".
- A named session's Overview has a **Repositories** block: each repository's branch, how far it is ahead or behind the session's base and its upstream, its merge request or Create MR, and its latest pipeline.
- **Main checkouts** has compact rows. Their actions show on hover, each with a tooltip.
- **Archive** is a page in the center of the live window. The side zones are gone: Chats, Council, Changes, Merge Requests, Pipelines, Log, Events, Terminal, Processes and Docs open as tabs from the New tab menu or the palette.

## Window and keys

- A rail at the window's left edge holds Sessions, Explorer when it is folded, Archive and Settings.
- Drag the Sessions and Explorer columns to resize them; Detached remembers their widths. The side columns of Processes, Settings and Council resize too.
- The center is one card, with tabs, `+`, split and `…` in a single header row. Switches and buttons look the same everywhere, and Explorer's modes are icons with counts. Fetch and Pull are icon buttons with tooltips.
- **Cmd+2** shows or hides Sessions, replacing Cmd+B. **Cmd+T** opens a terminal below the center in the current repository, or in the workspace's folder. Pull no longer has a shortcut: use its button or the palette. On Windows and Linux, Cmd is Ctrl.
- **Indigo** is the new default theme. In dark mode, cards stand apart from the window.
- Diff, file and log tabs show a spinner while they load. The path line at the bottom shows only for a document with a file.
