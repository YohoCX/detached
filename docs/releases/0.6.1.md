# Detached 0.6.1

## Workspaces and tabs

- **One workspace at a time.** A workspace is now its own context: the top bar's switcher picks the
  current one, and the sidebar, fetch and pull all, quick open, search and the Chats list cover its
  repos alone. Switching stops nothing: the other workspace's terminals and chats keep running.
  Your workspaces carry over.
- **Tabs by category.** The center's tabs sort into Docs, Chats and Code, shown as chips with their
  counts. Each workspace keeps its own tabs and the category you last showed. Ctrl+Tab and
  Ctrl+Shift+Tab change the category, Cmd+Shift+] and Cmd+Shift+[ the tab within it (Ctrl on
  Windows and Linux).
- **Chats as a tree.** The Chats app lists the workspace's folders, each over its own chats and its
  repos'. Nodes open and close by click or arrow keys and stay as you left them; search opens the
  ones it matches.
- **New chat** from the top bar's chat button, on the current repo, or its empty chat if it has one.

## Agents

- **Panels is now Council**; your settings, roles, modes, runs and saved tabs move over on first
  start.
- **No third-party MCP servers.** Chats and Council runs load no MCP server but Detached's own: not the
  ones in your `~/.claude.json`, a repo's `.mcp.json`, a plugin's or an agent file's, and not your
  claude.ai connectors. They run outside every permission rule and cost context on every turn.
  Extend the agents with skills that run scripts instead; your hooks and your accepted repos' hooks
  still run.
- **Codex's MCP servers are turned off by name**: Detached reads the server names in your
  `~/.codex/config.toml` (or `$CODEX_HOME`'s) and in the repo's `.codex/config.toml` at each start
  and turns each off for that session. A server Codex finds anywhere else still loads.
- **Council Stats** drops its Calibration section and its corpus run; the dispositions and the
  suggestion stay. Calibration comes back redesigned, with an estimate you confirm first.

## Look and feel

- **Settings redesigned:** every page in titled cards with rows, chips and switches; Skills lists
  one row per skill with where it comes from.
- **System, Light or Dark** on Settings › Appearance, beside the theme.
- **Catppuccin theme** (Latte light, Mocha dark), and Fleet with higher contrast: text, lines and a
  solid focus ring.
- **Polish:** popups, dialogs and tabs move; buttons and rows press. The chat reads in a column, a
  `/clear` the agent ran folds what came before behind "Context cleared", and Council's findings
  sit in three panes you can resize.
- **Open in Zed is gone** from the file and diff headers, the conflict bar and notice, the sidebar
  menu and the keymap.

## Fixes

- **Windows:** an agent's call to Detached's tools no longer drops when a process starts during
  it; the Chats tree names a folder by its last segment; a long terminal tab title (PowerShell's
  path) no longer pushes the tab's close button out of reach.
- **Diff:** F7 pressed while a diff reloads is no longer undone when the reload lands.
- **Chat:** a message sent right after trusting the repo's changed settings no longer shows twice.
- **Files:** a file that finishes loading in a tab you left no longer takes the focus.
- **WSL:** when Detached quits or crashes, the commands Claude started in the distro end with it.
- **Agents:** a crashed agent's error shows its last lines in full.

## Known limits

- A chat still works in one repo or folder. Chats across a workspace's projects, Council per
  workspace, read-only projects and the archive of older chats come in a later release.
- On Windows a Council reviews only subjects you trusted: the sandboxed review needs WSL, which this
  build does not do yet.
- The agents have been used by hand on macOS only. On Windows and Linux they have passed the
  automated tests alone.
