# Detached 0.6.1

## Agents

- **No third-party MCP servers.** Chats and panels load no MCP server but Detached's own: not the
  ones in your `~/.claude.json`, a repo's `.mcp.json`, a plugin's or an agent file's, and not your
  claude.ai connectors. They run outside every permission rule and cost context on every turn.
  Extend the agents with skills that run scripts instead; your hooks and your accepted repos' hooks
  still run.
- **Codex chats are off**, and Claude takes Codex's seats in a panel on a trusted subject: Codex
  cannot turn off your MCP servers for one session. With Codex on, it still takes the seats of a
  panel on a subject you have not trusted, which runs on a Codex home of its own.
- **Open in Zed is gone** from the file and diff headers, the conflict bar and notice, the sidebar
  menu and the keymap.
