# Detached 0.6.0

Detached now runs AI agents beside your repos. They run on the Claude Code you installed: the
`claude` command on your PATH, version 2.1.322 or later, on your own login and plan. Detached ships
no copy of Claude Code and never reads your login. It is an independent project, not made or
endorsed by Anthropic.

## Agents

- **Chats run on Claude Code directly.** No extra download: each chat is your `claude` with the
  model, effort and permission mode you pick. Past conversations are Claude Code's own, so those
  you started in a terminal show and resume too. The bar shows your plan's limits, and a
  subscription's cost shows as $0. A `claude` older than 2.1.322 gets a warning, and one Detached
  cannot talk to yet gets the installer's command for a version that works.
- **Permissions stay in Detached.** Each tool call that needs permission asks you; "Always" is
  kept by Detached for that exact call and never written into the repo. Agents are denied `.env`
  files.
- **Trust per repo.** A repo's agent settings (hooks, MCP servers, permissions, skills, commands)
  load only once you accept them, and a change asks again.
- **Panels.** Several agents on one subject: a review or a pre-merge gate of a branch, triage of a
  merge request or an issue, a review of a plan or any document. Another agent checks each finding
  before you see it. Fix, Dismiss or Defer each one; a Fix runs in its own worktree on its own
  branch, is checked again, and reaches your branch only when you click Merge. A merge request
  from a fork or any subject you have not trusted gets a sandboxed, read-only review and no Fix.
  Stats shows how each role, lens and model did. Past revmux rounds can be imported. macOS and
  Linux only for now.
- **Agents read the client.** Branches, merge requests, pipelines, docs and processes come to an
  agent through a read-only tool instead of pasted text.
- **Messages.** Chats you put in one group can send each other messages and wake each other up.
- **Skills** from `.claude/skills`, `~/.claude/skills`, `~/.agents/skills` and the repo's own
  store reach every chat. Settings › Skills lists them with where each comes from.
- **Docs.** The Docs app reads a repo's `docs/INDEX.md`, its plans and decisions, and marks a doc
  stale when the code it covers changed after it. A turn that changed covered code says which docs
  may need an update.
- **Processes.** Define a dev server or any command once and run it from the Processes app. Env
  profiles keep their values encrypted under a key in the system's credential store, and the log
  blanks them out. Each definition says whether agents may read its log or also start it.
- **Worktrees** from Settings › Worktrees, with a recipe of files to copy and an install command.
- **Sharing.** Skills, panel modes, recipes and process definitions are kept in the repo's git
  directory or shared with your team in `.detached/`.
- **`detached-cli`**, installed on PATH from Settings › Command line: a script in a Detached
  terminal tab can ask the client what it knows and run a command with an env profile once you
  confirm.

## Everything else

- Changes in your repos show as they happen: a file watcher replaces most refreshes.
- The Project tree shows dot files and git-ignored files, muted; Settings › Files hides names in
  every repository.
- Updates download on the Updates page with their progress and install on Restart now, which first
  names the chats and shells a restart ends.
- The terminal uses libghostty-vt on every OS, with Nerd Font icons built in.

## Known limits

- The agents have been used by hand on macOS only. On Windows and Linux they have passed the
  automated tests alone, and panels do not run on Windows yet.
- Codex support is built but stays off.
- The chat names Claude Code as "Claude Agent" for now.
